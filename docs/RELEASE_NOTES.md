# Leesavontuur 0.2.0-beta.4

De spreekstem is vernieuwd met ElevenLabs Jessica: levendige complimenten,
rustige instructies en woorden, met Nederlands als
ingestelde taal. De maker koos de levendige variant na het beluisteren van proeven.

- 1.458 lokale MP3s vervangen; 311 unieke fragmenten hergebruikt in de bundel.
- 183 losse leesklanken en hak-/plakreeksen behouden hun eerdere Piper-stem.
  Ook ingebedde doelklanken gebruiken deze bestanden.
- Nieuwe luisterpagina met 18 voorbeelden, bereikbaar via het oudergedeelte.
- Herkomst, instellingen en checksums per vervangen bestand vastgelegd.
- Audio blijft lokaal en offline afspeelbaar, zonder API-sleutel in de app.
- De Safari-herstelknop, gedeelde audiospeler, afwisselende complimenten en
  oefenreparaties uit bèta 3 blijven aanwezig.

De volledige uitspraakcontrole en een fysieke iPhone-test zijn nog open.
Alle 1.641 bestanden zijn synthetisch; de gekozen stijl is geen didactische
uitspraakgoedkeuring. Zie [ElevenLabs-productie](audio/ELEVENLABS_SETUP.md).
Dit blijft een begeleide bèta, nog geen volledig gevalideerde leesmethode.

## Bijwerken

Na een geslaagde Pages-workflow: open het oudergedeelte, kies **Controleer op een
update** en daarna **Open de nieuwe versie**. Sluit andere geopende appvensters
als de update daarom vraagt. Voortgang blijft lokaal bewaard.

De workflow publiceert de geteste build via GitHub Actions naar GitHub Pages.
